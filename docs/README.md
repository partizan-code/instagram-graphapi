# Документация

Практические руководства и устройство Instagram Graph API Toolkit.
Обзор возможностей, быстрый старт и краткие примеры — в [корневом README](../README.md).

| Документ | Содержание |
| --- | --- |
| [Настройка](SETUP.md) | Установка инструментов, `.env`, Meta-приложение, назначение переменных |
| [Авторизация](AUTHENTICATION.md) | Unified Login, проверки OAuth, получение и явный выпуск нового токена |
| [Direct](DIRECT.md) | Запросы чтения, выбор аккаунта, формат вывода и границы выборки |
| [Публикации](PUBLISHING.md) | Сигнатуры Python API, фото, Reels, Stories, карусели и ожидание обработки |
| [Webhooks](WEBHOOKS.md) | Запуск через tuna, callback и подписки Meta, проверка подписи, ограничения приёмника |
| [Архитектура](ARCHITECTURE.md) | Ответственность модулей, HTTP-слой и границы логирования |
| [Разработка и тесты](DEVELOPMENT.md) | Задачи mise, управление окружением и изоляция тестов |
| [Состояние проекта](../PROJECT_STATUS.md) | Подтверждённые результаты, ограничения и следующие проверки |

`mise run start` читает реальный API; примеры авторизации и публикации тоже
выполняют реальные операции при вызове. Для локальных изолированных проверок
используйте `mise run test` или `mise run check`.
