# Разработка

Приложение запускается обычным `main.py` без аргументов. Правила — в [AGENTS.md](../AGENTS.md).
Стандартный запуск: `mise run start`. Он обращается к реальному Instagram.

## Инструменты

`mise.toml` закрепляет Python 3.13.18 и uv 0.8.18. Зависимостями и окружением
управляет uv, mise запускает задачи. Окружение находится вне проекта:
`<xdg_data_home>/uv/venvs/insta-posting-<hash пути проекта>`.
Старый `venv/` сохранён. Новые окружения автоматически не создавайте.

```console
mise run setup
mise run tunnel
mise run webhook
mise run test
mise run lint
mise run format
mise run check
```

`check` выполняет Ruff lint, проверку форматирования и pytest. `--locked` запрещает
незаметное обновление lock-файла. Автоматическое форматирование допустимо только
при разработке, для файлов текущей задачи.

## Изоляция проверок

`tests/conftest.py` подставляет фиктивное окружение, отключает загрузку `.env`,
блокирует HTTP, socket-подключения и DNS. Тесты чтения подменяют HTTP-сессию и ответы.
Проверяются рабочий запрос, выбор аккаунта, вывод сообщений, предупреждение о
продолжении, безопасные ошибки, отсутствие повторов/отправки и закрытие ресурсов.
Тесты сохранения токена используют временные файлы. Вход проверяется с подменой
браузера и URL редиректа. Проверяются обмен кода, обновление бизнес-токена,
его proof, ошибки прав и запросы публикации фото, Reels, Stories и каруселей.
Webhook-тесты используют httpx ASGITransport с фиктивными ключами без HTTP-сервера.
Служебный socketpair asyncio на Windows создаётся перед включением сетевых
блокировок, которые затем действуют во всех тестах.

Не используйте main.py как тест без отдельного разрешения на конкретный аккаунт
и операцию. Отправка сообщений требует отдельного задания.

## Конфигурация

Настройки Meta и назначение переменных — в [SETUP.md](SETUP.md).
Секреты держите в `.env`, шаблон — `.env.example`. Переменные терминала приоритетнее.
Зависимости меняйте через uv; конфигурация проекта и lock-файл остаются в проекте.
Для VS Code выбирайте Python существующего UV_PROJECT_ENVIRONMENT.

Коммиты, push и перенос проекта требуют отдельного задания.
Не включайте секреты, переписку, логи и окружения в Git.

Запуск webhook-сервера, запрос адреса туннеля и настройка Meta — [WEBHOOKS.md](WEBHOOKS.md).
