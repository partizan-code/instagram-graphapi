# Правила проекта

## Интерфейс приложения

- Не использовать CLI-режим, команды, подкоманды и аргументы запуска приложения.
- Не добавлять `argparse`, `click`, `typer`, обработку `sys.argv`, консольные меню
  или выбор режима через переменную `ACTION` и подобные обходные решения.
- `main.py` — обычный сценарий без аргументов: проверка авторизации и вывод
  диалогов и доступной истории Instagram Direct в консоль.
- Операции авторизации, чтения и отправки оформлять как функции или методы Python.
  Параметры Python-функций допустимы; это не аргументы командной строки.
- Отправку сообщений не выполнять автоматически при запуске `main.py`.
- Выводить понятные сообщения на русском. Не выводить токены и секреты.
- Стандартный запуск — `mise run start`, без аргументов приложения.

## Логирование

- Использовать Loguru и общий `logger` из `logging_config.py`; не использовать `print`.
- Настраивать логирование централизованно через `configure_logging()`.
- По умолчанию писать только в консоль, без файлов с личной перепиской.
- Не логировать сырые HTTP-исключения/ответы с секретами и значения локальных переменных.
- Не добавлять маскирование секретов: не передавать секреты в записи логирования.

## Проверки

- Проверять поведение изолированными тестами с фиктивными данными и без сети.
- Запуск `main.py` обращается к реальному Instagram: не использовать его как тест
  без отдельного разрешения на конкретный аккаунт и операцию.
- Команды инструментов разработки mise, uv, Ruff и pytest не являются CLI
  интерфейсом приложения; существующий рабочий процесс разработки сохраняется.
